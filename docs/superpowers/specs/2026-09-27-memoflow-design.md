# MemoFlow 备忘录与 Blackboard 导入设计规格

日期：2026-09-27

## 1. 目标

MemoFlow 是一个面向个人使用的 Windows 桌面备忘录应用，核心能力是记录富文本备忘录、创建提醒，并在用户主动点击“同步 Blackboard”后，从 CUHK(SZ) Blackboard 总日历/活动页面导入课程作业、项目和其他带截止时间的项目。

第一版强调轻量、启动快和界面响应及时。数据保存在本机，未来可以增加云同步；第一版不要求学校开放 Blackboard API，也不安装浏览器扩展。

## 2. 已确认范围

### 2.1 产品范围

- Windows 电脑端优先，手机端后续考虑。
- 首页使用双栏工作台：左侧为“最近事项”，右侧为整月日历。
- 备忘录支持标题、正文、加粗、列表和链接等富文本。
- 支持分类、标签和关键词搜索。
- 提醒支持一次性和重复提醒。
- 提醒到点发送 Windows 系统通知，并在应用内保留待处理状态。
- 提醒操作支持“完成”和“忽略”，第一版不提供“稍后提醒”。
- 备忘录和提醒可以关联，也可以独立创建。
- 支持将备忘录导出为 Markdown 或纯文本。
- 本地保存，数据结构为未来云同步预留来源字段和同步状态。

### 2.2 Blackboard 导入范围

- 用户必须在 MemoFlow 内点击“同步 Blackboard”才会启动导入流程。
- 应用打开内置 Blackboard 登录窗口，用户自行完成学校 SSO 登录。
- 应用读取 Blackboard 总日历/活动页面中所有带截止时间的项目。
- 导入范围包括作业、项目、考试、课程活动及其他有截止时间的项目。
- 读取结果先进入预览页，用户可以逐条取消勾选，确认后才写入本地数据。
- 每个确认导入的项目生成一条备忘录和一个关联提醒，并保留 Blackboard 原始链接。
- 再次同步只新增或更新项目，不自动删除本地数据。
- 第一版不做后台定时同步、不依赖浏览器扩展、不要求云端服务。

## 3. 技术方案

### 3.1 推荐技术栈

- Tauri 2：轻量桌面应用外壳和 Windows 集成。
- Svelte + TypeScript：主界面和导入预览界面。选择 Svelte 是为了减少前端运行时负担并保持界面响应。
- Rust：本地业务逻辑、数据库访问、提醒调度和 Tauri 命令。
- SQLite：备忘录、提醒、外部项目和同步记录的本地持久化。
- Windows WebView2：应用内 Blackboard 登录和页面读取窗口。
- Windows Toast 通知：提醒到点后的系统通知。

### 3.2 组件边界

1. **主界面模块**
   - 显示左侧最近事项和右侧月历。
   - 提供新建、编辑、搜索、筛选、导出和“同步 Blackboard”入口。

2. **备忘录模块**
   - 管理富文本内容、分类、标签和来源信息。
   - 维护手动编辑内容，避免被 Blackboard 同步覆盖。

3. **提醒模块**
   - 管理一次性/重复提醒、完成和忽略状态。
   - 调度 Windows 通知，并在应用内显示待处理提醒。

4. **Blackboard 导入模块**
   - 创建和关闭独立 WebView2 窗口。
   - 让用户完成 SSO 登录。
   - 在总日历/活动页面读取课程、标题、类型、截止时间和原始链接。
   - 将解析结果交给预览和去重模块。

5. **同步与去重模块**
   - 比较外部项目 ID、链接、课程和标题。
   - 生成新增、已更新、已存在、未找到四类结果。
   - 保留用户对本地备忘录的编辑和提醒状态。

6. **本地数据模块**
   - 通过 Rust 访问 SQLite。
   - 提供事务和迁移机制。
   - 为未来云同步保留 `source`、`external_id`、`last_seen_at` 和同步状态字段。

## 4. 主要流程

### 4.1 普通备忘录和提醒

用户在主界面点击“新建”，填写标题和富文本正文，可选择分类、标签和提醒。保存后，备忘录出现在左侧最近事项中；有日期的提醒显示在右侧月历对应日期。独立提醒可以不关联备忘录。

### 4.2 Blackboard 导入

1. 用户点击“同步 Blackboard”。
2. MemoFlow 打开内置 WebView2 窗口并导航到 `https://bb.cuhk.edu.cn/`。
3. 用户手动完成学校 ADFS/SSO 登录。应用不接触密码输入内容。
4. 应用引导用户打开 Blackboard 总日历/活动页面；必要时提供“继续读取”按钮。
5. 应用在 WebView2 中读取页面内容，提取所有带截止时间的项目。
6. 解析结果进入预览页，按新增、更新、已存在和异常分组。
7. 用户取消不想导入的项目，点击“确认导入”。
8. 应用在一个本地事务中创建/更新备忘录、提醒和外部项目映射。
9. 完成后显示导入数量、跳过数量和异常数量，保留最近一次同步记录。

## 6. 去重和更新规则

- 首选 Blackboard 项目 ID 去重。
- 如果页面没有稳定 ID，则使用原始链接、课程标识、标题和截止时间组合判断。
- 标题或截止时间变化时，外部项目标记为“已更新”。
- 用户手动补充的备忘录正文、分类、标签和提醒状态不会被同步覆盖。
- Blackboard 中暂时消失的项目标记为“未找到”，不自动删除。
- 解析不到截止时间的项目可以显示在异常预览中，但不能直接创建提醒。

## 7. 视觉和交互方向

主界面使用现代生产力工具风格：深色侧栏、浅色内容区、圆角卡片、清晰留白、统一强调色和清晰的层级。主内容区域由两部分组成：

- 左侧“最近事项”：按时间列出即将到期和最近创建的项目，显示标题、时间和分类。
- 右侧“月历”：显示完整月份，单元格内展示提醒、课程作业和项目截止日期；支持上一月、下一月、回到今天和新建。

避免使用截图中那种密集表格、默认灰色控件、老式菜单栏和系统默认按钮。Blackboard 登录窗口的页面样式由学校平台决定，登录完成后的主界面、导入预览和提醒界面全部使用 MemoFlow 自定义样式。

## 8. 安全、隐私和异常处理

- 应用不保存学校密码，也不要求用户将密码粘贴到 MemoFlow。
- Blackboard 会话保存在本机应用窗口中；提供退出并清除会话功能。
- 课程页面内容不上传到第三方服务器。
- 取消登录不会写入任何导入数据。
- 页面打不开或网络中断时，保留本地备忘录功能，并允许重新同步。
- 没有识别到项目时不创建空提醒。
- 页面结构变化导致解析失败时，显示错误并停止导入，不静默产生错误数据。
- 所有导入写入在本地事务中完成，失败时回滚本次导入。

## 9. 验证和验收标准

### 9.1 先行验证

在完整 UI 之前，先制作一个最小 Tauri 验证版本，确认：

1. WebView2 可以打开 Blackboard 登录入口。
2. 用户可以完成学校 SSO 登录。
3. 登录后可以打开总日历/活动页面。
4. 应用可以读取至少一个课程项目的标题和截止时间。
5. 应用可以安全关闭窗口并清除会话。

如果验证版本无法稳定读取页面，暂停完整功能实现，改为评估学校 API 或手动文件导入方案。

### 9.2 功能验证

- 富文本备忘录可以创建、编辑、搜索、分类、标签和导出。
- 一次性和重复提醒可以创建，完成/忽略状态在重启后保持。
- Windows 通知按时间发送。
- Blackboard 同步只由用户点击启动。
- 导入预览可以取消单条项目，确认后才写入。
- 重复同步不会创建重复备忘录或提醒。
- 标题、截止时间更新和项目消失符合去重规则。
- 网络中断、登录取消、会话过期和页面结构异常都有明确反馈。

### 9.3 性能验证

- 主界面启动后交互保持即时响应。
- 本地搜索和月历切换不依赖网络。
- 导入几十个项目时预览生成不会阻塞主界面。
- 应用空闲时保持较低 CPU 和内存占用。

## 10. 非目标

- 第一版不做后台定时 Blackboard 同步。
- 第一版不做浏览器扩展。
- 第一版不要求 Blackboard REST API；如果以后获得 API 权限，只替换导入适配器。
- 第一版不做云账号和多设备同步。
- 第一版不做手机端完整界面。
- 第一版不修改 Blackboard 中的作业、课程或成绩数据。
