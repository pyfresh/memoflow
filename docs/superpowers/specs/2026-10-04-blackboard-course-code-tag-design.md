# Blackboard 课程代码标签设计

## 目标

Blackboard 导入的课程作业保留原始事项标题，并把课程代码作为独立标签显示。例如课程名为 `AIS6002:Science Foundation for Generative Model_01` 时，事项标签包含 `AIS6002`。

## 行为

- 优先使用 Blackboard 提供的 `courseCode` 字段。
- 缺少字段时，从课程名第一个冒号前提取非空课程代码。
- 课程代码只作为导入事项标签，不改变标题、提醒内容或课程表名称。
- 保留现有的事项类型标签，例如 `assignment`。
- 手动事项不受影响；无法识别课程代码时不添加空标签。
- 重新同步已有 Blackboard 事项时，补齐或更新课程代码标签，同时保留用户自定义标签，避免重复标签。

## 验收

- `AIS6002` 从课程名中正确提取并出现在导入事项标签中。
- 已有 `courseCode` 时优先使用字段值。
- 无课程代码时标签列表不包含空字符串或完整课程名替代标签。
- 同一事项重复同步不会重复添加课程代码标签。
- 现有 Blackboard 导入、仓储和 UI 测试全部通过。
